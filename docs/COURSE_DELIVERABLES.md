# CISC 520 academic deliverables

The following is a planning checklist transcribed and condensed from the instructor's project guidelines.

## Phase I: Problem Definition and Conceptual/Logical Model

- [ ] A. Project environment
- [ ] B. Existing system description
- [ ] C. Problems and opportunities
- [ ] D. Goals for new system
- [ ] E. Entities, attributes, identifiers, conceptual and logical ER models; data collection method
- [ ] F. Initial Gantt project plan and milestones
- [ ] G. Performance appraisal signed by all team members

## Phase II: Logical and Physical Models

- [ ] A. Phase I summary
- [ ] B. Modified conceptual/logical models and ER diagram
- [ ] C. Physical relational design including keys, constraints, normalization and metadata
- [ ] D. Updated Gantt and milestone schedule
- [ ] E. Performance appraisal signed by all team members

## Phase III: Database and Application Development

- [ ] A. Phases I and II summary
- [ ] B. Modified logical/physical models
- [ ] C. Implemented and populated tables, functioning forms, reports, queries and menus; screenshots or samples
- [ ] D. Prototype functionality and in-class demonstration

## For every written report and phase presentation

- [ ] Professional single integrated report with submission letter, cover sheet, table of contents and executive summary
- [ ] One or two weekly team meetings with meeting log, attendance, assigned tasks and signatures
- [ ] Every team member presents; phase I/II maximum 20 minutes, phase III maximum 45 minutes

**Note:** Project deadlines have not been independently confirmed. November 9–December 20, 2026 in the task tracker is a *provisional* six-week execution window.
